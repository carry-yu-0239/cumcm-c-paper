\subsection{高钾与铅钡玻璃二分类}

\subsubsection{候选模型}
本文优先比较以下低复杂度分类器：
\begin{itemize}
  \item 逻辑回归：输出类别概率，参数可解释；
  \item 线性判别分析：适用于类内协方差结构相对稳定的情形；
  \item 决策树：可提取直观阈值规则；
  \item 支持向量机：作为非线性或最大间隔对照模型。
\end{itemize}
最终模型依据分组交叉验证下的平衡准确率、宏平均F1值、ROC--AUC及模型简洁性综合确定，而非仅比较训练集准确率。

\subsubsection{分类规则表达}
若最终采用逻辑回归，则
\begin{equation}
  p_i=P(T_i=1\mid\bm{x}_i)
  =\frac{1}{1+\exp[-(\alpha_0+\bm{\alpha}^{\mathsf T}\bm{z}_i)]}.
\end{equation}
当\(p_i\ge c\)时判为铅钡玻璃，否则判为高钾玻璃；阈值\(c\)由交叉验证确定。若采用决策树，应在正文中提炼为不超过数层的可解释阈值规则。

\subsection{合理性与敏感性分析}
\begin{enumerate}
  \item \textbf{内部合理性：}比较类内距离、类间距离、轮廓系数等指标；
  \item \textbf{外部解释性：}检验亚类在关键成分上是否具有清晰且可解释的差异；
  \item \textbf{算法一致性：}比较层次聚类、K-means或高斯混合模型的分组一致率；
  \item \textbf{扰动稳定性：}对成分加入\(\pm1\%\)、\(\pm3\%\)等小扰动，重复聚类并计算调整兰德指数；
  \item \textbf{预处理敏感性：}比较原始闭合数据、标准化数据及CLR数据下的结果。
\end{enumerate}
