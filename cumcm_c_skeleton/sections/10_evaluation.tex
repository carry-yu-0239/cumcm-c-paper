\section{模型检验与稳健性分析}

\subsection{分类模型检验}
采用按文物编号分组的分层交叉验证，保证同一文物的多个采样点不会同时出现在训练集和测试集中。报告混淆矩阵、平衡准确率、宏平均F1值、灵敏度、特异度及ROC--AUC。
其中，问题三严格复现问题二14维CLR--PLS--DA的折外结果：准确率为0.9851、平衡准确率为0.9722、宏平均F1为0.9807；四变量对照模型的平衡准确率同为0.9722。未知样品最终类型始终由14维主模型给出，PbO树与四变量模型只用于可解释性和一致性核验。

\subsection{恢复模型检验}
若存在可用的未风化点或模拟留出样本，则报告平均绝对误差、均方根误差及成分和偏差：
\begin{align}
  \mathrm{MAE} &= \frac{1}{nD}\sum_{i=1}^n\sum_{j=1}^D
  \left|x_{ij}^{(0)}-\hat{x}_{ij}^{(0)}\right|,\\
  \mathrm{RMSE} &= \sqrt{\frac{1}{nD}\sum_{i=1}^n\sum_{j=1}^D
  \left(x_{ij}^{(0)}-\hat{x}_{ij}^{(0)}\right)^2}.
\end{align}
同时检查恢复后各成分是否非负、总和是否接近\(100\%\)。

\subsection{关键假设敏感性}
至少比较以下设定：
\begin{enumerate}
  \item 有效样本阈值和归一化方法；
  \item 零值替代量；
  \item 是否合并同一文物的普通部位；
  \item 是否对风化样品先恢复再分类；
  \item 分类器、聚类算法和聚类数；
  \item 输入成分的随机扰动幅度。
\end{enumerate}

对问题三的A1--A8，进一步在保持CLR零和约束下施加标准差0.03的局部高斯扰动，各样品重复100次；同时取近零替换参数$0.01\%,0.02\%,0.04\%$重算输入。两类检验下均未出现主模型类型翻转，但这只表明当前8件样品在给定扰动范围内稳定，不能外推为所有检测误差条件下均无不确定性。

\subsection{问题四关联稳健性}

问题四以Pearson相关为主结果，并以Spearman相关作秩稳健性对照；高钾、铅钡两类的91组成分对符号一致率分别为74.7\%和80.2\%，平均绝对差分别为0.169和0.131。进一步按文物编号完整删除其全部采样点后重算相关矩阵，两类的中位符号稳定率均为100.0\%，但最小值仅为43.8\%和47.5\%。因此正文只将稳定性较高的关联用于类型画像，并把低检出率成分和受单件文物影响的边缘关联列为谨慎解释对象；该检验不把同一文物的重复采样误当作独立删除单位。
