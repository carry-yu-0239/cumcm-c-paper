\section{数据预处理与描述}

\subsection{数据表关联}
表单1以文物编号为主键，包含纹饰、类型、颜色和表面风化信息；表单2以采样点为记录单位，包含已分类样品的14种成分；表单3包含未知类别样品的风化状态和化学成分。对表单2中的采样点名称提取文物编号后，与表单1完成匹配。

\subsection{有效性检验}
对每个采样点计算成分总和
\begin{equation}
  s_i=\sum_{j=1}^{14}x_{ij}.
\end{equation}
依据题意，仅保留满足
\begin{equation}
  85\le s_i\le105
\end{equation}

\subsection{空白值与零值处理}
题目规定空白表示未检测到该成分。用于汇总统计和有效性检验时，将其记为0；若使用CLR或ILR等对数比变换，则需先以小正数替代零值。设替代后含量为\(x_{ij}^{*}\)，再进行闭合归一化：
\begin{equation}
  c_{ij}=100\frac{x_{ij}^{*}}{\sum_{k=1}^{14}x_{ik}^{*}}.
\end{equation}

\subsection{重复采样点处理}
对“部位1/部位2”“未风化点”“严重风化点”等特殊记录保留其采样点层面的信息，同时以文物编号建立分组标识。主要模型按采样点分析，并通过以下方式检验重复采样影响：
\begin{enumerate}
  \item 将同一文物的普通部位取均值后重新建模；
  \item 采用按文物分组的交叉验证，避免同一文物的采样点同时进入训练集和测试集；
  \item 对特殊风化点单独进行案例比较，不与普通采样点机械合并。
\end{enumerate}
